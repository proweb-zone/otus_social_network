# Онлайн обновление ленты новостей

## Цель

Разработать WebSocket сервер, при помощи которого подключенные клиенты будут сразу получать обновления постов своих друзей. Такой подход позволит сэкономить ресурсы и обновлять молниеносно ленты активных клиентов.

## Результат

1) Реализовал REST API Создание поста (метод /post/create)
2) Реализовал асинхронное API с websocket (метод /post/feed/posted)
3) Реализовал отложенную материализацию ленты
- Добавил в docker composer сервис rabbitmq
- Реализовал отправку поста пользователя в отдельный канал (пример названия userid_1)

При получении ленты новостей через метод /post/feed/posted, мы получим список id друзей пользователя и подпишемся на все каналы друзей

При отправке новости друга пользователя, мы получим сообщения из очереди через таймаут 2 секунды.

# Запуск и проверка ДЗ

1) Зайдите в CLI и скачайте репозитарий проекта с GitHub
```
git clone https://github.com/proweb-zone/otus_social_network.git
```
2) В CLI переходим в корень проекта и запускаем docker compose
```
docker compose up -d
```

3) Далее нужно провести миграцию БД
```
make migration-up
```
4) Через postman создаем 3 тестовых пользователя (перед этим нужно загрузить Postman коллекцию из корня проекта)

5) Авторизуем каждого пользователя и получаем токены доступа (Bearer token)
6) Добавляем друг друга в друзья, меняя только только токены авторизации (в api - id пользователя получаем из токена авторизации), если хотите добавить кого то в друзья, нужно в запросе указать ваш токен и get параметром передать id друга (смотри пример из postman коллекции)

7) В Postman делаем запрос на получение ленты новостей друзей (метод http://localhost:3002/post/feed/posted)
8) В Postman открываем несколько вкладок на создания поста и вводим Barer token друзей пользователя и создаем по новости каждого пользователя
9) Заходим в docker desktop и в логах приложения должны выводиться все новости друзей
Пример скриншота ленты новостей находиться по адресу https://github.com/proweb-zone/otus_social_network/tree/main/load_test/lesson_6/scrin_chat.png
