# Кеширование

### Цель домашнего занятия

В результате выполнения ДЗ вы создадите ленту постов друзей социальной сети

В данном задании тренируются навыки:

- работа с кешами;
- работа с очередями;
- проектирование масштабируемых архитектур.

## Результат выполнения:

#### 1) Реализовал следующие методы API
- Добавление/удаление друга (методы /friend/add, /friend/delete из спецификации)
- CRUD для постов пользователей (методы /post/create, /post/update, /post/delete, /post/get из спецификации)
- Лента постов друзей (метод /post/feed из спецификации)

Ссылка на коллекцию Postman  находиться в корне реапозитария https://github.com/proweb-zone/otus_social_network/blob/main/otus_social_network.postman_collection.json

#### 2) Разработал структуру БД для хранения постов пользователей

### 3) Реализовал кэширование ленты с помощью Redis

- Лента друзей формируется на основе кешей, как только пользователь оставляет пост, тот он тут же записывается в кеш.
- С помощью Redis реализовано хранение последний 1000 постов друзей. Данный срез данных можно задать средствами библиотеки на Go

```
postsListRedis, err := r.Client.ZRevRangeWithScores(ctx, key, 0, 999).Result()
		if err != nil {
			return nil, err
		}
```
- А инвалидация кеша достигается за счет удаление старых сообщений из Redis (все что больше 1000 постов удалется - замещается на свежие данные)

```
r.Client.ZRemRangeByRank(ctx, "feeds", 0, -1001)
```
