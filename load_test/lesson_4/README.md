# Кеширование

### Цель домашнего занятия

В результате выполнения ДЗ вы создадите ленту постов друзей социальной сети

В данном задании тренируются навыки:

- работа с кешами;
- работа с очередями;
- проектирование масштабируемых архитектур.

## Результат выполнения:

### 1) Реализовал следующие методы API
- Добавление/удаление друга (методы /friend/add, /friend/delete из спецификации)
- CRUD для постов пользователей (методы /post/create, /post/update, /post/delete, /post/get из спецификации)
- Лента постов друзей (метод /post/feed из спецификации)

Ссылка на коллекцию Postman  находиться в корне реапозитария https://github.com/proweb-zone/otus_social_network/blob/main/otus_social_network.postman_collection.json

### 2) Разработал структуру БД для хранения постов пользователей

### 3) Реализовал кэширование ленты с помощью Redis

- Лента друзей формируется на основе кешей, как только пользователь оставляет пост, тот он тут же записывается в кеш.
- С помощью Redis реализовано хранение последний 1000 постов друзей. Данный срез данных можно задать средствами библиотеки на Go

```
postsListRedis, err := r.Client.ZRevRangeWithScores(ctx, key, 0, 999).Result()
		if err != nil {
			return nil, err
		}
```
- А инвалидация кеша достигается за счет удаление старых сообщений из Redis (все что больше 1000 постов удалется - замещается на свежие данные)

```
r.Client.ZRemRangeByRank(ctx, key, 0, -1001)
```


# Запуск и проверка ДЗ

1) Зайдите в CLI и скачайте репозитарий проекта с GitHub
```
git clone https://github.com/proweb-zone/otus_social_network.git
```

2) В CLI переходим в корень проекта и запускаем docker compose
```
docker compose up -d
```

3) Далее нужно провести миграцию БД
```
make migration-up
```

4) Через postman создаем 3 тестовых пользователя (перед этим нужно загрузить Postman коллекцию из корня проекта)

5) Авторизуем каждого пользователя и получаем токены доступа (Bearer token)
6) Добавляем друг друга в друзья, меняя только только токены авторизации (в api - id пользователя получаем из токена авторизации), если хотите добавить кого то в друзья, нужно в запросе указать ваш токен и get параметром передать id друга (смотри пример из postman коллекции)
7) прогреваем БД моковыми данными (постами)

```
 go run app/cmd/build_data/build_posts.go 1 2 3
 ```

где 1 2 3 - это id зарегистрированных пользователей (передаются в cli), по необходимости можете заменить на свои id передав их через пробел в строку

### Примечание:

 Данные будут записываться в БД и REDIS. Кешироваться будут только по 1000 сообщений каждого пользователя, чтобы при запросе ленты новостей друзей получать закешированную ленту.
